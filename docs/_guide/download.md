Navifast is in development. Build from
[the repository](https://github.com/nizarcan/navifast) using the pinned Rust
toolchain. Follow [Getting started](/getting-started/).

The repository's existing version and release notes are inherited history.
There is not yet a published Navifast release to install from Homebrew, AUR,
Flathub or an automatic updater.
